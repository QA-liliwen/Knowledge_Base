# 修改setting.py

1.import static

2.修改为app名和项目名的地方
INSTALLED_APPS，ROOT_URLCONF，WSGI_APPLICATION

3.其余修改

| 修改项              | 默认值     | 修改为                                | 说明                                 |
| ---------------- | ------- | ---------------------------------- | ---------------------------------- |
| ALLOWED_HOSTS    | []      | ['*']                              | `*` 表示允许所有域名访问，开发方便，生产环境不安全        |
| CSRF 中间件         | 启用      | 注释掉了                               | 关掉后前端 POST 不用带 csrf_token，方便调试但不安全 |
| TEMPLATES DIRS   | []      | ['xlsx']                           | 模板目录指向 xlsx 文件夹，用于放 Excel 相关模板     |
| LANGUAGE_CODE    | 'en-us' | 'zh-hans'                          | 中文简体，Admin 后台显示中文                  |
| TIME_ZONE        | 'UTC'   | 'Asia/Shanghai'                    | 上海时区，时间显示北京时间                      |
| STATICFILES_DIRS | 无       | [os.path.join(BASE_DIR, 'static')] | 静态文件目录，放 CSS/JS/图片                 |

# 创建数据库

```py
from django.db import models  


class Interface(models.Model):
    """接口元数据"""
    name = models.CharField('接口名称', max_length=200)  
    url = models.CharField('请求URL', max_length=500)  
    method = models.CharField('请求方法', max_length=10)  
    headers = models.JSONField('请求头', default=dict, blank=True)  
    params = models.JSONField('请求参数', default=dict, blank=True)  
    description = models.TextField('描述', blank=True)  
    is_del = models.BooleanField('是否删除', default=False)  
    created_at = models.DateTimeField(auto_now_add=True)    
    
    class Meta:  
        verbose_name = '接口'
        verbose_name_plural = '接口'
        
    def __str__(self):
        return f"{self.name} ({self.method} {self.url})"
```
