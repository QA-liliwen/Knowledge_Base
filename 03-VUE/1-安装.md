
1.安装
https://nodejs.org
npm -v

2.安装 vue-cli
npm install -g @vue/cli

3.创建项目
vue create vue_project

4.配置

| 问题  | 选择                                                            | 说明                        | 描述                             |
| --- | ------------------------------------------------------------- | ------------------------- | ------------------------------ |
| 1   | Please pick a preset                                          | Manually select features  | 默认预设不含Router，需手动选              |
| 2   | Check the features needed                                     | Babel ✓、Router ✓、Linter取消 | Router用于页面路由；不要ESLint，和参考项目一致  |
| 3   | Choose a version of Vue.js                                    | 2.x                       | 参考项目用的Vue 2                    |
| 4   | Use history mode for router?                                  | n                         | hash模式（URL带#），不需要后端额外配置        |
| 5   | Where do you prefer placing config\|In dedicated config files | In dedicated config files | 生成独立的babel.config.js，和参考项目结构一致 |
| 6   | Save this as a preset?                                        | n                         | 不保存预设，仅本次使用                    |


5.默认项目结构
D:\code\api_project\vue_project\
├── node_modules/            ← 依赖包目录（npm install自动生成，不手动改）
├── public/
│   ├── favicon.ico          ← 浏览器标签页小图标
│   └── index.html           ← 唯一HTML入口，Vue挂载到其中的<div id="app">
├── src/
│   ├── assets/                     ← 静态资源目录（图片、css等放这里）
│   │   └── logo.png
│   ├── components/                ← 子组件视图（自己的组件放这）
│   │   └── HelloWorld.vue
│   ├── views/                           ← 父组件视图（路由/指向的页面）
│   │   ├── HomeView.vue
│   │   └── AboutView.vue
│   ├── App.vue              ← 根组件，所有页面的外壳（放公共布局、导航栏）
│   ├── main.js              ← JS入口：创建Vue实例、挂载路由、引入全局css
│   └── router/
│       └── index.js         ← 路由配置：定义URL路径和页面组件的对应关系
├── babel.config.js          ← Babel编译配置（ES6转ES5）
├── package.json             ← 项目依赖清单和npm脚本（serve/build命令）
├── package-lock.json        ← 依赖版本锁定文件（自动生成）
└── .gitignore               ← git忽略规则（node_modules等不提交）
