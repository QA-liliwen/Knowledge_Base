## 实现内容

Vue 前端采用 `vue-router` 的 history 模式，页面通过 URL 路径切换；后端 Django 提供 REST 接口，前端使用 axios 直接请求后端地址。

## 代码

### `src/main.js`：入口挂载路由

```js
import Vue from 'vue'
import App from './App.vue'
import router from './router'
import 'bootstrap/dist/css/bootstrap.min.css'

Vue.config.productionTip = false

new Vue({
  router,
  render: h => h(App)
}).$mount('#app')
```

**关键点**：

- `import router from './router'` 引入路由配置。
- `new Vue({ router, render: h => h(App) })` 把路由实例注入 Vue 根实例，全局组件可通过 `this.$router` / `this.$route` 访问。
- `mode: 'history'` 去除 URL 中的 `#`。

### `src/router/index.js`：路由表

```js
import Vue from 'vue'
import VueRouter from 'vue-router'
import HomeView from '../views/HomeView.vue'
import InterfaceView from '../views/InterfaceView.vue'
import RunResultView from '../views/RunResultView.vue'
import ToolsView from '../views/ToolsView.vue'

Vue.use(VueRouter)

const routes = [
  {
    path: '/api_list/:tag_id/',
    name: 'home',
    component: HomeView
  },
  {
    path: '/interfaces/',
    name: 'interfaces',
    component: InterfaceView
  },
  {
    path: '/run_results/',
    name: 'run_results',
    component: RunResultView
  },
  {
    path: '/tools/:tool_key/',
    name: 'tools',
    component: ToolsView
  },
  {
    path: '/tools/',
    name: 'tools_index',
    component: ToolsView
  },
  {
    path: '/api_list/',
    redirect: '/api_list/1/'
  }
]

const router = new VueRouter({
  mode: 'history',
  routes
})

export default router
```

**关键点**：

- `/api_list/:tag_id/` 是一级标签对应的测试项页，`tag_id` 作为路由参数。
- `/api_list/` 默认重定向到 `/api_list/1/`，保证首次进入首页有默认一级标签。
- `/tools/` 同时支持带 `tool_key` 与不带两种路径，后者由组件内部自动跳转到第一个工具。

### `src/App.vue`：只放一个路由视图

```vue
<template>
  <div id="app">
    <router-view/>
  </div>
</template>
```

**关键点**：

- 整个应用只有一个 `<router-view/>`，不直接放 TopMenu；每个 View 组件按需引入 TopMenu。
- 这样接口列表、测试结果、工具箱等独立页面可以只加载各自需要的组件。

## 前后端对接方式

| 前端页面 | 路由路径 | 主要后端接口 |
|---|---|---|
| 测试项首页 | `/api_list/:tag_id/` | `get_top_menu/`、`get_second_tags/`、`get_grouped_test_items/`、`execute_run/` 等 |
| 接口列表 | `/interfaces/` | `get_interface_list/`、`update_interface/`、`delete_interface/` 等 |
| 测试结果 | `/run_results/` | `get_run_result_list/`、日志下载接口 |
| 工具箱 | `/tools/:tool_key/` | `get_tools/`、各工具后端接口 |

**关键点**：

- 前端所有 axios 请求都写死后端地址 `http://172.16.2.60:8000/xxx/`，本地开发阶段没有配置代理。
- 路由参数通过 `this.$route.params.tag_id` / `this.$route.params.tool_key` 读取。
