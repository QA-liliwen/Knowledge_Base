## 实现内容

测试结果页包含两类下载：Jenkins 构建产物（日志、HTML 报告）和本地单接口日志文件。测试项弹窗展示某次执行包含的测试项名称列表。

## 代码

### `src/components/api_test/RunResultList.vue`：测试项弹窗

```vue
<!-- 测试项弹窗 -->
<div v-if="item_modal.show" class="modal-backdrop" @click.self="item_modal.show = false">
    <div class="modal-dialog-custom">
        <div class="modal-header-custom">
            <h5>测试项列表</h5>
            <button type="button" class="btn-close" @click="item_modal.show = false"></button>
        </div>
        <div class="modal-body" style="max-height: 400px; overflow-y: auto">
            <div v-for="(name, idx) in item_modal.names" :key="idx" style="padding: 6px 0; border-bottom: 1px solid #f0f0f0">
                {{ idx + 1 }}. {{ name }}
            </div>
            <div v-if="item_modal.names.length === 0" style="color: gray">暂无测试项</div>
        </div>
        <div class="modal-footer">
            <button type="button" class="btn btn-secondary" @click="item_modal.show = false">关闭</button>
        </div>
    </div>
</div>
```

```js
data() {
    return {
        jenkins_results: [],
        local_results: [],
        item_modal: {
            show: false,
            names: []
        }
    }
},
methods: {
    show_items(item) {
        this.item_modal.names = item.test_item_names || []
        this.item_modal.show = true
    }
}
```

**关键点**：

- 弹窗数据只保存 `names` 数组，不保存 id，因为结果页只需要展示名称。
- 点击遮罩（`@click.self`）或关闭按钮可关闭弹窗。
- `modal-body` 设置 `max-height: 400px` 和 `overflow-y: auto`，测试项多时可滚动。

## 下载与弹窗的触发方式

| 元素 | 触发方法/条件 | 目标 |
|---|---|---|
| 测试项“查看”按钮 | `show_items(item)` | 弹窗展示 `test_item_names` |
| Jenkins 日志 | `item.log_file && item.jenkins_build_url` | Jenkins artifact 日志 |
| Jenkins 报告 | `item.report_file && item.jenkins_build_url` | Jenkins artifact 报告 |
| Jenkins 链接 | `item.jenkins_build_url` | Jenkins 构建页 |
| 本地日志 | `item.log_file && item.test_type === 1` | 后端 `download_log/` |
| 本地操作 Jenkins | `item.jenkins_build_url` | Jenkins 构建页 |

## 后端接口

### `views_test_item.py`：下载日志文件

```py
LOG_DIR = os.path.join(BASE_DIR, "data", "logs")

def download_log(request):
    filename = request.GET.get('filename', '')
    if not filename or '..' in filename or '/' in filename:
        return JsonResponse({"msg": "文件名不合法"}, status=400)
    file_path = os.path.join(LOG_DIR, filename)
    if not os.path.exists(file_path):
        raise Http404("日志文件不存在")
    return FileResponse(open(file_path, 'rb'), as_attachment=True, filename=filename)
```

**关键点**：

- 从 `data/logs/` 目录读取日志文件并以附件形式返回。
- 安全检查与 `download_script` 相同：文件名不能包含 `..` 和 `/`。
- 本地执行时日志写入 `data/logs/`，前端通过 `download_log/?filename=xxx` 下载。
- 前端目前只对 `test_type === 1`（单接口用例）展示下载按钮。
