## 实现内容

右侧 `RunList.vue` 面板展示执行配置：域名、环境、Token、请求头模板，以及已勾选测试项列表；点击执行后弹出二次确认框，选择 local/jenkins 模式并填写说明，最后把参数提交到后端 `execute_run/`。

### `src/components/api_test/RunList.vue`：数据与事件监听

```js
<script>
    import axios from 'axios'
    import bus from '../../bus'
    export default {
        data(){
            return{
                domains: [],
                envs: [],
                tokens: [],
                header_templates: [],
                selected_domain: '',
                selected_env: '',
                selected_token: '',
                selected_header_template: '',
                running: false,
                selected_items: [],
                selected_ids: [],
                show_dialog: false,
                run_mode: 'local',
                run_description: '',
            }
        },
        mounted:function () {
            this.get_config()
            bus.$on('items:changed', payload => {
                this.selected_items = payload.names
                this.selected_ids = payload.ids
            })
        },
        beforeDestroy(){
            bus.$off('items:changed')
        },
        methods:{
            get_config(){
                axios.get('http://172.16.2.60:8000/get_run_config/').then(res=>{
                    this.domains = res.data.domains;
                    this.envs = res.data.envs;
                    this.tokens = res.data.tokens;
                    this.header_templates = res.data.header_templates;
                })
            },
            // do_execute 详见下方
        }
    }
</script>
```

**关键点**：

- 配置从 `get_run_config/` 统一拉取，避免多个接口分别请求。
- `mounted` 中通过 `bus.$on('items:changed')` 监听测试项勾选变化；`beforeDestroy` 中移除监听，防止内存泄漏。
- `selected_items` / `selected_ids` 由 event bus payload 直接赋值。

### `src/components/api_test/RunList.vue`：执行提交

```js
do_execute(){
    if (this.selected_ids.length === 0) {
        alert('请先选择测试项');
        return
    }
    this.running = true;

    const payload = {
        test_item_ids: this.selected_ids,
        domain_id: this.selected_domain || null,
        env_id: this.selected_env || null,
        token_id: this.selected_token || null,
        header_template_id: this.selected_header_template || null,
        description: this.run_description,
        run_mode: this.run_mode,
    };

    axios.post('http://172.16.2.60:8000/execute_run/', payload).then(res=>{
        this.show_dialog = false;
        this.run_description = '';
        const results = res.data.results || [];
        const runIds = results.map(r => r.run_id).join(', ');
        const jenkinsUrl = (results.find(r => r.jenkins_build_url) || {}).jenkins_build_url;
        if (jenkinsUrl) {
            alert('Jenkins 执行已提交，run_id=' + runIds + '\n构建链接：' + jenkinsUrl);
        } else {
            alert('本地执行已提交，run_id=' + runIds);
        }
    }).catch(err=>{
        console.error('执行失败：', err);
        const msg = err.response?.data?.message || err.response?.data?.msg || err.message || '未知错误';
        alert('执行失败：' + msg);
    }).finally(()=>{
        this.running = false
    })
}
```

**关键点**：

- 提交到 `execute_run/`，后端按 `run_mode` 分发到本地执行或 Jenkins 执行。
- 空字符串的下拉选择统一转为 `null` 传给后端。
- 后端可能一次返回多个 `results`（按类型拆分执行），前端把 `run_id` 拼接展示。
- 如果有 Jenkins 构建链接，额外展示在 alert 中。

## 执行配置参数说明

| 字段 | 来源 | 含义 |
|---|---|---|
| `test_item_ids` | 左侧勾选 | 待执行测试项 id 列表 |
| `domain_id` | 域名下拉 | 拼接接口 URL 时使用 |
| `env_id` | 环境下拉 | 拼接接口 URL 时使用 |
| `token_id` | Token 下拉 | 获取认证 token 并加入请求头 |
| `header_template_id` | 请求头模板下拉 | 公共请求头 |
| `description` | 执行弹窗输入 | 本次执行说明 |
| `run_mode` | local/jenkins 单选 | 执行方式 |

## 后端接口

### `views_test_item.py`：获取执行配置

```py
def get_run_config(request):
    domains = list(DB_Domain.objects.filter(is_del=False).values('id', 'name'))
    envs = list(DB_Env.objects.filter(is_del=False).values('id', 'name'))
    tokens = list(DB_Token.objects.filter(is_del=False).values('id', 'name'))
    header_templates = list(DB_HeaderTemplate.objects.filter(is_del=False).values('id', 'name'))
    return JsonResponse({
        "domains": domains,
        "envs": envs,
        "tokens": tokens,
        "header_templates": header_templates,
    })
```

**关键点**：

- 一个接口返回四类配置数据，前端四个下拉框各取一个数组。
- 每个数组只返回 `id` 和 `name`，实际值（domain、env、token、headers）在执行时由后端另行查询。
- 四类数据都只返回未软删除的记录。
