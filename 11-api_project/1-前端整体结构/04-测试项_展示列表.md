## 实现内容

`TestItemList.vue` 按二级标签分组展示测试项表格；支持分组收起/展开、分组全选、单条勾选；每条测试项提供编辑入口，分组头部提供新建入口。

### `src/components/api_test/TestItemList.vue`：数据与全选逻辑

```js
<script>
    import axios from 'axios'
    import bus from '../../bus'
    export default {
        data(){
            return{
                groups: [],
                checked_ids: [],
                // 其他字段省略
            }
        },
        mounted:function () {
            this.get_groups()
            // 其他初始化省略
        },
        methods:{
            get_groups(){
                const tag_id = this.$route.params.tag_id;
                axios.get('http://172.16.2.60:8000/get_grouped_test_items/', {
                    params: {first_tag_id: tag_id}
                }).then(res=>{
                    this.groups = res.data.groups.map(g => ({...g, collapsed: false}));
                    this.checked_ids = [];
                })
            },
            type_name(type){
                const map = {1: '单接口用例', 2: '多接口脚本'}
                return map[type] || '未知'
            },
            is_all_selected(group){
                if (group.test_items.length === 0) return false
                return group.test_items.every(item => this.checked_ids.includes(item.id))
            },
            toggle_all(group){
                const ids = group.test_items.map(item => item.id)
                if (this.is_all_selected(group)) {
                    this.checked_ids = this.checked_ids.filter(id => !ids.includes(id))
                } else {
                    this.checked_ids = [...new Set([...this.checked_ids, ...ids])]
                }
                this.up_checked()
            },
            toggle(id){
                if (this.checked_ids.includes(id)) {
                    this.checked_ids = this.checked_ids.filter(i => i !== id)
                } else {
                    this.checked_ids.push(id)
                }
                this.up_checked()
            },
            up_checked(){
                const checked_names = this.get_checked_names();
                this.$emit('upItems', {checked_ids: this.checked_ids, checked_names: checked_names, count: this.checked_ids.length})
                // 通过 event bus 直接通知 run_list（绕开 prop 响应性 HMR 问题）
                bus.$emit('items:changed', {
                    ids: this.checked_ids.slice(),
                    names: checked_names.slice(),
                })
            },
            get_checked_names(){
                const names = [];
                for (const group of this.groups) {
                    for (const item of group.test_items) {
                        if (this.checked_ids.includes(item.id)) {
                            names.push(item.name)
                        }
                    }
                }
                return names;
            },
            open_edit(item){
                // 详见 05
            },
            open_create(second_tag_id){
                // 详见 06
            },
        },
        watch:{
            '$route'(){
                this.get_groups()
            }
        }
    }
</script>
```

**关键点**：

- `groups` 从后端 `get_grouped_test_items/` 获取，加载时给每个 group 注入 `collapsed: false` 默认展开。
- `checked_ids` 保存所有分组的已勾选 id；`is_all_selected` 判断当前分组是否已全选。
- `toggle_all` 会合并或移除当前分组所有 id，跨分组勾选不会被清空。
- `toggle` 点击整行切换勾选，但编辑按钮通过 `@click.stop` 阻止冒泡，避免误触发勾选。
- `up_checked` 同时做两件事：
  - `$emit('upItems')` 向上通知父组件（目前父组件只打印日志）；
  - `bus.$emit('items:changed')` 通过 event bus 通知右侧 `RunList.vue` 更新待执行列表。

## 列表交互流程

1. 进入首页或切换一级标签 → `get_groups()` 拉取分组数据 → 渲染二级标签分组表格。
2. 用户点击分组“收起” → `group.collapsed = true` → `<tbody v-show="!group.collapsed">` 隐藏。
3. 用户点击行或勾选框 → `toggle` / `toggle_all` 更新 `checked_ids` → `up_checked` 通知右侧 RunList。
4. 用户点击“编辑” → `open_edit(item)` 拉取详情 → 打开弹窗。
5. 用户点击分组“新建” → `open_create(group.second_tag_id)` → 打开弹窗并预填二级标签。

## 后端接口

### `views_test_item.py`：按二级标签分组获取测试项

```py
def get_grouped_test_items(request):
    first_tag_id = request.GET.get("first_tag_id")
    second_tags = DB_SecondTag.objects.filter(is_del=False, first_tag_id=first_tag_id).order_by('sort', 'id')
    groups = []
    for tag in second_tags:
        items = list(DB_TestItem.objects.filter(is_del=False, second_tag=tag).order_by('sort', 'id').values('id', 'name', 'type', 'description', 'created_at'))
        groups.append({
            "second_tag_id": tag.id,
            "second_tag_name": tag.name,
            "test_items": items
        })
    return JsonResponse({"groups": groups})
```

**关键点**：

- 先查出一级标签下的所有二级标签，再逐个查询每个二级标签下的测试项，组装为 `groups` 数组。
- 每个 group 包含 `second_tag_id`、`second_tag_name` 和 `test_items` 三个字段。
- 测试项只返回 `id`、`name`、`type`、`description`、`created_at` 五个字段，不返回 `cases` 等大字段。
- 前端加载时为每个 group 注入 `collapsed: false` 控制收起/展开。
