## 实现内容

`RunResultList.vue` 展示两类执行记录：Jenkins 执行和本地执行，各用一张表格呈现；表格包含状态、统计、时间、日志/报告/链接等列；点击“查看”可弹出测试项列表。

### `src/components/api_test/RunResultList.vue`：数据与工具方法

```js
<script>
    import axios from 'axios'
    export default {
        data() {
            return {
                jenkins_results: [],
                local_results: [],
                item_modal: {
                    show: false,
                    names: []
                }
            }
        },
        mounted() {
            this.get_list()
        },
        methods: {
            get_list() {
                axios.get('http://172.16.2.60:8000/get_run_result_list/').then(res => {
                    this.jenkins_results = res.data.jenkins || []
                    this.local_results = res.data.local || []
                })
            },
            status_class(status) {
                const map = {
                    'running': 'bg-info',
                    'passed': 'bg-success',
                    'failed': 'bg-danger',
                }
                return map[status] || 'bg-secondary'
            },
            type_name(type) {
                const map = { 1: '单接口', 2: '多接口' }
                return map[type] || '-'
            },
            format_time(t) {
                if (!t) return '-'
                return t.replace('T', ' ').substring(0, 19)
            },
            show_items(item) {
                this.item_modal.names = item.test_item_names || []
                this.item_modal.show = true
            }
        }
    }
</script>
```

**关键点**：

- 一个接口 `get_run_result_list/` 同时返回 `jenkins` 和 `local` 两个数组。
- `status_class` 用 bootstrap badge 颜色区分 running/passed/failed。
- `format_time` 把后端返回的 ISO 时间格式化成 `YYYY-MM-DD HH:mm:ss`。

## 页面跳转与数据流

1. 用户在 TopMenu 点击“测试结果” → 路由跳转到 `/run_results/` → `RunResultView.vue` 渲染 `RunResultList.vue`。
2. `RunResultList.vue` 加载时调用 `get_list()` 拉取两类执行记录。
3. 用户点击“查看” → `show_items(item)` 把该记录的测试项名称写入弹窗 → 显示弹窗。
4. 用户点击日志/报告/链接 → 打开对应 URL（Jenkins 产物或本地下载接口）。

## 后端接口

### `views_test_item.py`：获取测试结果列表

```py
def get_run_result_list(request):
    jenkins_results = list(DB_run_result.objects.filter(trigger_source='jenkins').order_by('-id')[:20].values(
        'id', 'description', 'status', 'total', 'passed', 'failed', 'skipped',
        'started_at', 'finished_at', 'duration_seconds',
        'trigger_source', 'env', 'jenkins_build_url', 'log_file', 'report_file', 'test_items'
    ))
    local_results = list(DB_run_result.objects.exclude(trigger_source='jenkins').order_by('-id')[:20].values(
        'id', 'description', 'status', 'total', 'passed', 'failed', 'skipped',
        'started_at', 'finished_at', 'duration_seconds',
        'trigger_source', 'env', 'jenkins_build_url', 'log_file', 'report_file', 'test_items'
    ))

    def _enrich(results):
        for r in results:
            r['test_type'] = None
            r['test_item_names'] = []
            ids = [i.strip() for i in str(r['test_items']).split(',') if i.strip()]
            if ids:
                items = DB_TestItem.objects.filter(id__in=ids)
                r['test_item_names'] = [item.name for item in items]
                first_item = items.first()
                if first_item:
                    r['test_type'] = first_item.type
        return results

    return JsonResponse({
        "jenkins": _enrich(jenkins_results),
        "local": _enrich(local_results),
    })
```

**关键点**：

- 按 `trigger_source` 分为 `jenkins` 和 `local` 两组，各取最近 20 条记录。
- `_enrich` 函数为每条记录补充 `test_type` 和 `test_item_names`：
  - `test_items` 是逗号拼接的 ID 字符串，拆分后批量查询测试项名称。
  - `test_type` 取第一个测试项的 type，前端根据此值区分"单接口"/"多接口"。
- 前端 Jenkins 表格和本地表格分别渲染这两个数组。
