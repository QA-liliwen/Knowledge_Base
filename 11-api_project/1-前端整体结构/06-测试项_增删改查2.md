## 实现内容

完成测试项的脚本上传、保存时区分新建/修改、软删除逻辑。脚本上传与 Excel 上传共用同一个字段名 `fileUpload`，但上传到不同后端接口。

## 代码

### `src/components/api_test/TestItemList.vue`：多接口脚本上传

```js
upload_script(){
    const scriptInput = this.$refs.scriptInput;
    if (!scriptInput || !scriptInput.files || scriptInput.files.length === 0) {
        return;
    }
    const formData = new FormData();
    formData.append('fileUpload', scriptInput.files[0]);
    axios.post('http://172.16.2.60:8000/upload_script/', formData, {
        headers: {'Content-Type': 'multipart/form-data'}
    }).then(res => {
        if (res.data.filename) {
            this.edit_form.script_filename = res.data.filename;
            this.edit_form.uploaded_script = res.data.filename;  // 标记本次新上传
        } else {
            alert(res.data.msg || '上传失败');
        }
    }).catch(err => {
        alert('上传失败: ' + (err.response?.data?.msg || err.message));
    })
},
clear_script(){
    this.edit_form.script_filename = '';
    this.edit_form.uploaded_script = '';
    if (this.$refs.scriptInput) {
        this.$refs.scriptInput.value = '';
    }
},
clear_file(){
    this.edit_form.uploaded_filename = '';
    if (this.$refs.fileInput) {
        this.$refs.fileInput.value = '';
    }
},
```

**关键点**：

- 脚本上传到 `upload_script/`，接口仍为 `multipart/form-data`，字段名同样叫 `fileUpload`。
- 后端返回脚本在服务器上的保存文件名（`filename`），前端记录到 `script_filename` 用于回显，同时记录到 `uploaded_script` 表示本次新上传。
- `clear_script` 和 `clear_file` 目前只在代码里定义，模板中没有直接调用入口，供后续扩展。

### `src/components/api_test/TestItemList.vue`：保存（新建/修改统一入口）

```js
save_edit(){
    let cases = [];
    if (this.edit_form.cases_json) {
        try {
            cases = JSON.parse(this.edit_form.cases_json);
        } catch (e) {
            alert('用例 JSON 格式错误');
            return;
        }
    }
    const isScript = this.edit_form.type === 2;
    const payload = {
        id: this.edit_form.is_create ? null : this.edit_form.id,
        second_tag_id: this.edit_form.second_tag_id,
        name: this.edit_form.name,
        type: this.edit_form.type,
        description: this.edit_form.description,
        // type=1 传接口和用例，type=2 置空
        interface_id: isScript ? null : this.edit_form.interface_id,
        cases: isScript ? [] : cases,
        // type=1 传 xlsx，type=2 传脚本
        uploaded_filename: isScript ? '' : this.edit_form.uploaded_filename,
        uploaded_script: isScript ? this.edit_form.uploaded_script : '',
    };
    axios.post('http://172.16.2.60:8000/update_test_item/', payload).then(res => {
        if (res.data.code === 0) {
            this.show_modal = false;
            this.get_groups();
        } else {
            alert(res.data.message || '保存失败');
        }
    }).catch(err => {
        alert('请求失败: ' + err.message);
    })
},
```

**关键点**：

- 后端 `update_test_item/` 一个接口同时处理新建和修改，通过 `id` 是否为空区分。
- 前端根据 `type` 动态置空不相关字段，避免把单接口的 interface_id/cases 误传给多接口脚本，反之亦然。
- `cases_json` 在提交前做一次 `JSON.parse` 校验，格式错误直接提示并终止提交。

### `src/components/api_test/TestItemList.vue`：软删除

```js
soft_delete(){
    if (!confirm('确定要删除这个测试项吗？')) return;
    axios.post('http://172.16.2.60:8000/update_test_item/', {
        id: this.edit_form.id,
        is_del: true
    }).then(res => {
        if (res.data.code === 0) {
            this.show_modal = false;
            this.get_groups();
        } else {
            alert(res.data.message || '删除失败');
        }
    }).catch(err => {
        alert('请求失败: ' + err.message);
    })
},
```

**关键点**：

- 删除复用同一个 `update_test_item/` 接口，只传 `id` 和 `is_del: true`。
- 后端执行软删除（数据库里只标记 `is_del`），不影响已有执行记录。

## 新建与修改的字段差异

| 字段 | 新建 | 修改 |
|---|---|---|
| `id` | `null` | 测试项 id |
| `is_create` | `true` | `false` |
| `second_tag_id` | 从分组带入 | `null`（不可修改） |
| `cases_json` | 空字符串 | 从详情 `JSON.stringify` 回填 |
| `script_filename` | 空字符串 | 从详情回填 |
| `uploaded_filename` | 空字符串 | 空字符串（仅本次新上传才有值） |
| `uploaded_script` | 空字符串 | 空字符串（仅本次新上传才有值） |

## 保存时 payload 按 type 过滤规则

| 字段 | type=1 单接口 | type=2 多接口 |
|---|---|---|
| `interface_id` | 实际值 | `null` |
| `cases` | 解析后的数组 | `[]` |
| `uploaded_filename` | 本次上传的 Excel 文件名 | `''` |
| `uploaded_script` | `''` | 本次上传的脚本文件名 |

## 后端接口

### `views_test_item.py`：上传脚本文件

```py
def upload_script(request):
    os.makedirs(TEMP_DIR, exist_ok=True)
    file = request.FILES.get("fileUpload")
    if not file or not file.name.endswith(".py"):
        return JsonResponse({"msg": "请上传 .py 文件"}, status=400)
    script_filename = file.name
    file_path = os.path.join(TEMP_DIR, script_filename)
    with open(file_path, "wb") as f:
        for chunk in file.chunks():
            f.write(chunk)
    return JsonResponse({"msg": "上传成功", "filename": script_filename})
```

**关键点**：

- 与 `upload_case` 共用字段名 `fileUpload`，但上传到不同接口。
- 只接受 `.py` 文件，存到 `data/temp/` 临时目录。
- 保存时从临时目录移到正式目录 `data/scripts/`。

### `views_test_item.py`：下载脚本文件

```py
def download_script(request):
    filename = request.GET.get('filename', '')
    if not filename or '..' in filename or '/' in filename:
        return JsonResponse({"msg": "文件名不合法"}, status=400)
    file_path = os.path.join(SCRIPTS_DIR, filename)
    if not os.path.exists(file_path):
        raise Http404("文件不存在")
    return FileResponse(open(file_path, 'rb'), as_attachment=True, filename=filename)
```

**关键点**：

- 从 `data/scripts/` 目录读取脚本文件并以附件形式返回。
- 安全检查：文件名不能包含 `..` 和 `/`，防止路径穿越攻击。
- `FileResponse` 自动处理 Content-Disposition 头，`as_attachment=True` 触发浏览器下载。

### `views_test_item.py`：更新或创建测试项

```py
def update_test_item(request):
    if request.method != 'POST':
        return JsonResponse({"code": -1, "message": "仅支持 POST 请求"}, status=405)
    if not request.body:
        return JsonResponse({"code": -1, "message": "请求体为空"}, status=400)
    try:
        data = json.loads(request.body)
    except json.JSONDecodeError:
        return JsonResponse({"code": -1, "message": "请求体不是合法 JSON"}, status=400)

    item_id = data.get('id')
    is_create = not item_id or item_id == 'new'

    if is_create:
        second_tag_id = data.get('second_tag_id')
        if not second_tag_id:
            return JsonResponse({"code": -1, "message": "新建测试项需要选择二级标签"}, status=400)
        item = DB_TestItem(second_tag_id=second_tag_id)
    else:
        item = DB_TestItem.objects.filter(id=item_id, is_del=False).first()
        if not item:
            return JsonResponse({"code": -1, "message": "测试项不存在"}, status=404)

    if data.get('is_del'):
        item.is_del = True
        item.save()
        return JsonResponse({"code": 0, "message": "删除成功"})

    item.name = data.get('name', item.name if not is_create else '未命名')
    item.type = data.get('type', item.type if not is_create else 1)
    item.description = data.get('description', item.description if not is_create else '')

    interface_id = data.get('interface_id')
    if interface_id is not None:
        item.interface_id = interface_id if interface_id != '' else None

    cases = data.get('cases')
    if cases is not None:
        item.cases = cases

    script_filename = data.get('script_filename')
    if script_filename is not None:
        item.script_filename = script_filename

    item.save()

    # 保存时移动 xlsx 文件从临时目录到正式目录
    uploaded_filename = data.get('uploaded_filename')
    if uploaded_filename:
        os.makedirs(XLSX_DIR, exist_ok=True)
        temp_path = os.path.join(TEMP_DIR, uploaded_filename)
        new_name = f"{item.id}_{uploaded_filename}"
        final_path = os.path.join(XLSX_DIR, new_name)
        if os.path.exists(temp_path):
            if os.path.exists(final_path):
                os.remove(final_path)
            shutil.move(temp_path, final_path)

    # 保存时移动脚本文件从临时目录到正式目录
    uploaded_script = data.get('uploaded_script')
    if uploaded_script:
        os.makedirs(SCRIPTS_DIR, exist_ok=True)
        new_name = f"{item.id}_{uploaded_script}"

        # 删除旧脚本文件（避免孤儿文件）
        old_script_filename = item.script_filename
        if old_script_filename and old_script_filename != new_name:
            old_script_path = os.path.join(SCRIPTS_DIR, old_script_filename)
            if os.path.exists(old_script_path):
                os.remove(old_script_path)

        # 从临时目录移到正式目录
        temp_path = os.path.join(TEMP_DIR, uploaded_script)
        final_path = os.path.join(SCRIPTS_DIR, new_name)
        if os.path.exists(temp_path):
            if os.path.exists(final_path):
                os.remove(final_path)
            shutil.move(temp_path, final_path)
        item.script_filename = new_name
        item.save(update_fields=['script_filename'])

    return JsonResponse({"code": 0, "message": "保存成功", "id": item.id})
```

**关键点**：

- 新建/修改/删除三合一接口，通过 `id` 和 `is_del` 区分操作类型。
- 新建时 `id` 为空或 `'new'`，必须传 `second_tag_id`。
- 删除只传 `id` 和 `is_del: true`，软删除不影响已有执行记录。
- Excel 文件保存时从 `data/temp/` 移到 `data/xlsx/`，重命名为 `{item_id}_{原文件名}`。
- 脚本文件保存时从 `data/temp/` 移到 `data/scripts/`，重命名为 `{item_id}_{原文件名}`。
- 移动脚本前先删除旧脚本文件，避免产生孤儿文件。
- `save()` 后才拿到 `item.id`，所以文件重命名必须在 `save()` 之后。
