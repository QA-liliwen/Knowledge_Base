## 实现内容

测试项弹窗根据 `type` 动态展示不同输入项：单接口用例（type=1）显示关联接口、测试 JSON、Excel 上传；多接口脚本（type=2）显示脚本上传。编辑时从后端拉取详情，新建时预填二级标签。

### `src/components/api_test/TestItemList.vue`：打开编辑与新建

```js
open_edit(item){
    axios.get('http://172.16.2.60:8000/get_test_item_detail/', {
        params: {id: item.id}
    }).then(res => {
        if (res.data.code === 0) {
            const d = res.data.data;
            this.edit_form = {
                id: d.id,
                is_create: false,
                second_tag_id: null,
                name: d.name,
                type: d.type,
                description: d.description,
                interface_id: d.interface_id,
                cases_json: JSON.stringify(d.cases, null, 2),
                uploaded_filename: '',
                script_filename: d.script_filename || '',
                uploaded_script: '',
            };
            this.show_modal = true;
        } else {
            alert(res.data.message || '获取详情失败');
        }
    })
},
open_create(second_tag_id){
    this.edit_form = {
        id: null,
        is_create: true,
        second_tag_id: second_tag_id,
        name: '',
        type: 2,
        description: '',
        interface_id: null,
        cases_json: '',
        uploaded_filename: '',
        script_filename: '',
        uploaded_script: '',
    };
    this.show_modal = true;
},
```

**关键点**：

- 编辑时请求 `get_test_item_detail/` 拿到完整详情，把 `cases` 数组格式化为 JSON 字符串供 textarea 编辑。
- 新建时默认 `type: 2`（多接口脚本），并传入 `second_tag_id` 预填二级标签。
- `uploaded_filename` 和 `uploaded_script` 用来记录本次弹窗中新上传的文件名；`script_filename` 用于回显已有脚本。

### `src/components/api_test/TestItemList.vue`：Excel 上传

```js
upload_file(){
    const fileInput = this.$refs.fileInput;
    if (!fileInput || !fileInput.files || fileInput.files.length === 0) {
        return;
    }
    const formData = new FormData();
    formData.append('fileUpload', fileInput.files[0]);
    axios.post('http://172.16.2.60:8000/upload_case/', formData, {
        headers: {'Content-Type': 'multipart/form-data'}
    }).then(res => {
        if (res.data.cases) {
            this.edit_form.cases_json = JSON.stringify(res.data.cases, null, 2);
            this.edit_form.uploaded_filename = res.data.filename || '';
        } else {
            alert(res.data.msg || '解析失败');
        }
    }).catch(err => {
        alert('上传失败: ' + (err.response?.data?.msg || err.message));
    })
},
```

**关键点**：

- 上传文件字段名固定为 `fileUpload`，与后端 `request.FILES.get('fileUpload')` 对应。
- 上传成功后，后端返回解析好的 `cases` 数组和文件名，前端回填到 `cases_json` 并记录 `uploaded_filename`。
- 上传失败时优先显示后端返回的 `msg`。

## 后端接口

### `views_test_item.py`：获取测试项详情

```py
def get_test_item_detail(request):
    item_id = request.GET.get('id')
    item = DB_TestItem.objects.filter(id=item_id, is_del=False).first()
    if not item:
        return JsonResponse({"code": -1, "message": "测试项不存在"}, status=404)
    return JsonResponse({
        "code": 0,
        "data": {
            "id": item.id,
            "name": item.name,
            "type": item.type,
            "description": item.description,
            "interface_id": item.interface_id,
            "cases": item.cases,
            "script_content": item.script_content,
            "script_filename": item.script_filename,
            "sort": item.sort,
        }
    })
```

**关键点**：

- 编辑弹窗打开时调用，返回完整字段供回填。
- `cases` 是 JSON 数组，前端用 `JSON.stringify(d.cases, null, 2)` 格式化后放入 textarea。
- `script_filename` 用于回显已上传脚本的文件名和下载链接。
- 找不到时返回 404，前端 alert 提示。

### `views_test_item.py`：获取接口列表（下拉框）

```py
def get_interfaces(request):
    interfaces = list(DB_Interface.objects.filter(is_del=False).order_by('sort', 'id').values('id', 'name'))
    return JsonResponse({"interfaces": interfaces})
```

**关键点**：

- 只返回 `id` 和 `name`，供测试项编辑弹窗的"关联接口"下拉框使用。
- 与 `get_interface_list/` 不同，该接口不返回 URL、方法等字段。
