## 实现内容

- 一级标签由 `TopMenu.vue` 从后端获取并展示在顶部，点击后跳转到对应 `/api_list/:tag_id/`。
- 二级标签由 `SideMenu.vue` 根据当前路由的 `tag_id` 从后端获取，展示在左侧；点击二级标签后，页面自动滚动到测试项列表中对应分组的位置。

## 代码

### `src/components/TopMenu.vue`：一级标签获取与展示

```vue
<template>
  <nav class="navbar navbar-expand-sm navbar-light border-bottom" style="padding: 0">
    <div class="container-fluid">
      <div class="collapse navbar-collapse" id="topMenuCollapse">
        <ul class="navbar-nav" style="margin-left: 40px">
          <li class="nav-item" v-for="tag in first_tags" :key="tag.id">
            <a class="nav-link" style="color: black;margin-right: 20px;font-size: 20px" href="#" @click.prevent="select_tag(tag)"
             :class="{active: String(tag.id) === active_tag_id}">{{ tag.name }}</a>
          </li>
          <!-- 固定菜单省略：接口列表、测试结果、工具箱 -->
        </ul>
        <!-- 右侧外链省略 -->
      </div>
    </div>
  </nav>
</template>

<script>
    import axios from 'axios'
    export default {
        data(){
            return{
                first_tags: [],
                active_tag_id: null,
            }
        },
        mounted:function () {
            this.active_tag_id = this.$route.params.tag_id;
            axios.get('http://172.16.2.60:8000/get_top_menu/').then(res=>{
                this.first_tags = res.data.first_tags;
            })
        },
        methods:{
            select_tag(tag){
                const path = '/api_list/' + tag.id + '/'
                if (this.$route.path !== path) {
                    this.$router.push(path)
                }
            }
        },
        watch: {
          '$route'(to) {
            this.active_tag_id = to.params.tag_id;
          }
        }
    }
</script>
```

**关键点**：

- `active_tag_id` 初始化为路由参数 `tag_id`，保证刷新或直接进入某标签页时高亮正确。
- `String(tag.id) === active_tag_id` 是因为 Vue 模板里从 `$route.params` 读到的值是字符串，而后端返回的 `id` 可能是数字。
- 监听 `$route` 后再次同步 `active_tag_id`，支持浏览器前进/后退。

### `src/components/api_test/SideMenu.vue`：二级标签获取与展示

```vue
<template>
    <div class="list-group">
        <a href="#" class="list-group-item list-group-item-action"
           v-for="tag in second_tags" :key="tag.id"
           @click.prevent="select_second(tag)">{{ tag.name }}</a>
    </div>
</template>

<script>
    import axios from 'axios'
    export default {
        data(){
            return{
                second_tags: [],
                active_second_id: null,
            }
        },
        mounted:function () {
            this.get_second_tags()
        },
        methods:{
            get_second_tags(){
                const tag_id = this.$route.params.tag_id;
                axios.get('http://172.16.2.60:8000/get_second_tags/', {
                    params: {first_tag_id: tag_id}
                }).then(res=>{
                    this.second_tags = res.data.second_tags;
                    this.active_second_id = null;
                })
            },
            select_second(tag){
                this.active_second_id = tag.id;
                this.$emit('upSecond', {second_tag_id: tag.id, second_tag_name: tag.name})
                const el = document.getElementById('second-tag-' + tag.id);
                if (el) {
                    el.scrollIntoView({behavior: 'smooth', block: 'start'});
                }
            }
        },
        watch:{
            '$route'(){
                this.get_second_tags()
            }
        }
    }
</script>

<style scoped>
    .list-group{
        width: 18%;
        margin-top: 20px;
        padding: 15px 0;
        position: fixed;
        top: 40px;
        left: 1%;
    }
    .list-group-item{
        font-size: 16px;
        border: none;
        border-radius: 0;
    }
</style>
```

**关键点**：

- `get_second_tags` 根据当前路由的 `tag_id` 请求后端，一级标签切换时二级菜单自动刷新。
- 点击二级标签时通过 `scrollIntoView` 让中间测试项列表滚动到 `id="second-tag-" + tag.id` 的元素位置。
- 该锚点元素定义在 `TestItemList.vue` 的 `v-for` 外层 div 上。

## 标签联动流程

1. 用户点击顶部一级标签。
2. `TopMenu.vue` 调用 `this.$router.push('/api_list/' + tag.id + '/')`。
3. `HomeView.vue` 的 `router-view` 保持不变，`SideMenu.vue` 监听 `$route` 变化，重新请求 `get_second_tags/`。
4. 左侧二级标签更新；`TestItemList.vue` 也监听 `$route` 变化，重新请求 `get_grouped_test_items/`，中间列表按二级标签分组渲染。
5. 用户点击左侧二级标签，触发 `scrollIntoView`，中间列表平滑滚动到对应分组。

## 后端接口

### `views_test_item.py`：获取一级标签

```py
def get_top_menu(request):
    first_tags = list(DB_FirstTag.objects.filter(is_del=False).order_by('sort', 'id').values())
    return JsonResponse({"first_tags": first_tags})
```

**关键点**：

- `order_by('sort', 'id')` 先按序号排序，序号相同时按 id 排序。
- `.values()` 不指定字段时返回所有字段，前端用到 `id` 和 `name`。

### `views_test_item.py`：获取二级标签

```py
def get_second_tags(request):
    first_tag_id = request.GET.get("first_tag_id")
    second_tags = list(DB_SecondTag.objects.filter(is_del=False, first_tag_id=first_tag_id).order_by('sort', 'id').values('id', 'name', 'sort'))
    return JsonResponse({"second_tags": second_tags})
```

**关键点**：

- 通过 `first_tag_id` 查询参数过滤，只返回当前一级标签下的二级标签。
- `.values('id', 'name', 'sort')` 只返回三个字段，减少传输数据量。
