# 02-改造日志配置：build_jenkins_log_config

## 实现内容

本地 `log_config.py` 的日志目录是相对路径 `../data/logs`，Jenkins 工作区不存在该目录。`build_jenkins_log_config` 读取原始配置并动态替换路径和初始化逻辑，生成适配 Jenkins 工作区的版本。

## 代码来源

`api_app/api_test/api_jenkins_single_runner.py`

---

## 原始 log_config.py

```py
import os
import logging
from logging.handlers import TimedRotatingFileHandler

# 日志根目录
LOG_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "../data/logs")
DEFAULT_FORMAT = "%(asctime)s [%(levelname)s] [%(name)s] %(message)s"
DEFAULT_DATEFMT = "%Y-%m-%d %H:%M:%S"
```

**关键点**：

- 本地执行时日志写到 `data/logs/`，通过相对路径 `../data/logs` 定位。
- Jenkins 工作区结构不同，该路径不存在，需要替换。

---

## 改造函数

```py
def build_jenkins_log_config():
    with open(os.path.join(BASE_DIR, "log_config.py"), "r", encoding="utf-8") as f:
        content = f.read()
    content = content.replace('"../data/logs"', '"logs"')
    content = content.replace(
        'DEFAULT_FORMAT',
        'os.makedirs(os.path.join(os.path.dirname(os.path.abspath(__file__)), "logs"), exist_ok=True)\nDEFAULT_FORMAT',
        1
    )
    return content
```

**关键点**：

- 第一步替换：`"../data/logs"` → `"logs"`，日志目录改为当前目录下的 `logs/`。
- 第二步替换：在 `DEFAULT_FORMAT` 前插入一行 `os.makedirs(..., exist_ok=True)`，确保日志目录存在后再创建 Handler。
- `replace(..., 1)` 只替换第一个 `DEFAULT_FORMAT`，避免替换掉后面的格式化字符串引用。
- 返回改造后的字符串内容，供 `pack_test_bundle` / `pack_custom_bundle` 写入 zip 包。

## 改造后效果

```py
import os
import logging
from logging.handlers import TimedRotatingFileHandler

# 日志根目录
LOG_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "logs")
os.makedirs(os.path.join(os.path.dirname(os.path.abspath(__file__)), "logs"), exist_ok=True)
DEFAULT_FORMAT = "%(asctime)s [%(levelname)s] [%(name)s] %(message)s"
DEFAULT_DATEFMT = "%Y-%m-%d %H:%M:%S"
```

**关键点**：

- Jenkins 端 pytest 执行时，日志写入工作区 `logs/` 目录。
- `Archive the artifacts` 配置 `logs/*.log` 可自动归档。
