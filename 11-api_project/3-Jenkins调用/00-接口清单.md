# Jenkins 调用 - 接口清单

来源：`api_project/urls.py`

| URL | 视图函数 | 说明 | 笔记位置 |
|---|---|---|---|
| `execute_run/` | `execute_run` | 执行入口，`run_mode=jenkins` 时走 Jenkins 分支 | 03-执行时测试项整合 |
| `update_run_result/` | `update_run_result` | Jenkins 构建完毕后 conftest.py 回调 | 06-测试结果回调 |

**说明**：

- Jenkins 执行与本地执行共用 `execute_run/` 入口，由前端 `run_mode` 参数区分。
- `dispatch_run()` 内部判断 `run_mode == 'jenkins'` 时调用 `trigger_jenkins_build()`。
- Jenkins 构建结束后，工作区的 conftest.py 回调 `update_run_result/` 更新最终状态。
- Jenkins 配置（Job、服务器地址、认证）硬编码在 `api_jenkins_single_runner.py` 和 `api_jenkins_custom_runner.py` 中，不通过接口暴露。
