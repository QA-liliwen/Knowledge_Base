# 断言解析与执行

`run_main` 状态码断言通过后，遍历用例的 `assertions` 列表，根据断言前缀或运算符分发到不同的断言处理函数。

---

## 流程

```
拿到 resp_json
  → 遍历 case['assertions']
  → 判断是否有前缀（len/exists/type/header/in）
  → 有前缀 → 调用对应断言函数
  → 无前缀 → 按路径取值，与期望值比较
```

---

## 运算符表与表达式解析

来源：`api_app/api_test/run_request.py`

```py
OPS = {
    '==': lambda a, e: a == e,
    '!=': lambda a, e: a != e,
    '>=': lambda a, e: float(a) >= float(e),
    '<=': lambda a, e: float(a) <= float(e),
    '=': lambda a, e: a == e,
    '>': lambda a, e: float(a) > float(e),
    '<': lambda a, e: float(a) < float(e),
}


def parse_expr(expr):
    for op in OPS:
        if op in expr:
            path, expected = expr.split(op, 1)
            return path.strip(), op, expected.strip()
    raise ValueError(f"断言格式错误，未找到运算符: {expr}")
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `'='` 单独存在 | Excel 里用户可能写 `=` 而不是 `==`，兼容处理 |
| `>=` `<=` 排在 `>` `<` 前面 | 避免 `>=` 被 `>` 先匹配截断 |
| `split(op, 1)` | 只按第一个运算符分割，期望值里再有运算符也不影响 |
| `path.strip()` / `expected.strip()` | 去除前后空格，兼容 Excel 复制出来的空白 |
| 找不到运算符抛 `ValueError` | 格式错误直接中断，便于排查 |

## 按路径取值

来源：`api_app/api_test/run_request.py`

```py
def extract_by_path(resp_json, path):
    data = resp_json
    keys = [k for k in path.strip('/').split('/') if k]
    for key in keys:
        if isinstance(data, list):
            key = int(key)
        data = data[key]
    return data
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `path.strip('/')` | 去掉首尾的 `/`，兼容 `/data/id` 和 `data/id` |
| `if k` | 过滤空字符串，防止连续斜杠导致报错 |
| `isinstance(data, list)` | 路径中的数字表示数组下标，需要转 int |
| `data[key]` | 逐层取值，支持 `/data/0/examId` 这种嵌套路径 |

## 期望值类型转换

来源：`api_app/api_test/run_request.py`

```py
def convert_expected(expected):
    if len(expected) >= 2 and expected[0] == expected[-1] and expected[0] in ('"', "'"):
        return expected[1:-1]

    expected_lower = expected.lower()
    if expected_lower == "true":
        return True
    if expected_lower == "false":
        return False
    if expected_lower in ("null", "none"):
        return None

    for i in (int, float):
        try:
            return i(expected)
        except ValueError:
            pass

    return expected
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| 引号包裹直接返回字符串 | `"abc"` 或 `'abc'` 强制按字符串比较 |
| `true` / `false` 转布尔 | 支持 JSON 风格布尔值 |
| `null` / `none` 转 None | 兼容大小写和两种写法 |
| 先尝试 int 再尝试 float | 能转整数尽量转整数，避免 1 和 1.0 不一致 |
| 都失败按字符串处理 | 兜底，保持原始字符串 |

## 长度断言

来源：`api_app/api_test/run_request.py`

```py
def assert_len(expr, resp, resp_json):
    path, op, expected = parse_expr(expr)
    actual = len(extract_by_path(resp_json, path))
    log.debug(f"长度断言: len({path}) 实际={actual} {op} 期望={expected}")
    try:
        assert OPS[op](actual, int(expected)), f"len({path}) 实际={actual} {op} 期望={expected}"
    except AssertionError:
        log.error(f"长度断言失败: len({path}) 实际={actual} {op} 期望={expected}")
        raise
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `len:` 前缀 | 对路径取到的数组/字符串计算长度 |
| `int(expected)` | 长度是整数，期望值必须转 int |
| `OPS[op]` | 复用通用运算符表 |
| `try/except AssertionError` | 失败时先记 error 日志，再抛出异常 |

## 存在性断言

来源：`api_app/api_test/run_request.py`

```py
def assert_exists(expr, resp, resp_json):
    log.debug(f"存在性断言: {expr}")
    try:
        extract_by_path(resp_json, expr)
    except (KeyError, IndexError, TypeError):
        log.error(f"存在性断言失败: 字段不存在: {expr}")
        raise AssertionError(f"字段不存在: {expr}")
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `exists:` 前缀 | 只判断字段是否存在，不判断值 |
| 捕获 `KeyError/IndexError/TypeError` | 字段不存在、数组越界、非容器类型都视为不存在 |
| 不返回值 | 能取到值即断言通过 |

## 类型断言

来源：`api_app/api_test/run_request.py`

```py
def assert_type(expr, resp, resp_json):
    path, op, expected = parse_expr(expr)
    data = extract_by_path(resp_json, path)
    actual = type(data).__name__
    if actual == 'NoneType':
        actual = 'none'
    log.debug(f"类型断言: {path} 实际={actual} 期望={expected}")
    try:
        assert actual == expected, f"{path} 实际类型={actual}, 期望={expected}"
    except AssertionError:
        log.error(f"类型断言失败: {path} 实际类型={actual}, 期望={expected}")
        raise
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `type:` 前缀 | 判断字段类型 |
| `type(data).__name__` | 取类型名字符串，如 list/dict/str |
| `NoneType` 转 `none` | 统一用 `none` 表示，方便用户写 |

## 响应头断言

来源：`api_app/api_test/run_request.py`

```py
def assert_header(expr, resp, resp_json):
    name, op, expected = parse_expr(expr)
    actual = resp.headers.get(name)
    log.debug(f"响应头断言: {name} 实际={actual} {op} 期望={expected}")
    try:
        assert actual is not None, f"响应头不存在: {name}"
        if not OPS[op](actual, expected) and op in ('=', '=='):
            actual = actual.split(';')[0].strip()
        assert OPS[op](actual, expected), f"响应头 {name} 实际={actual} {op} 期望={expected}"
    except AssertionError:
        log.error(f"响应头断言失败: {name} 实际={actual} {op} 期望={expected}")
        raise
```

### 特殊处理原因

| 代码 | 特殊处理原因 |
|------|-------------|
| `header:` 前缀 | 判断响应头 |
| `resp.headers.get(name)` | requests 响应头字典不区分大小写 |
| `actual.split(';')[0]` | Content-Type 常带 `; charset=utf-8`，取前半段比较 |
| 只在 `=`/`==` 失败时做分割 | 其他运算符不处理，避免误伤 |

## 成员断言

来源：`api_app/api_test/run_request.py`

```py
def assert_in(expr, resp, resp_json):
    path, op, expected = parse_expr(expr)
    data = extract_by_path(resp_json, path)
    allowed = [convert_expected(v.strip()) for v in expected.split('|')]
    log.debug(f"成员断言: {path} 实际={data} 候选列表={allowed}")
    try:
        assert data in allowed, f"{path} 实际={data} 不在候选列表 {allowed}"
    except AssertionError:
        log.error(f"成员断言失败: {path} 实际={data} 不在候选列表 {allowed}")
        raise
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `in:` 前缀 | 判断实际值是否在候选列表中 |
| `expected.split('\|')` | 多个候选值用 `\|` 分隔 |
| `convert_expected(v.strip())` | 每个候选值都做类型转换 |

## 断言分发主循环

来源：`api_app/api_test/run_request.py`

```py
def run_main(case):
    # 【前面发请求和状态码断言逻辑见 04-pytest执行入口】
    resp_json = resp.json()

    for assertion_str in case['assertions']:
        ASSERT_HANDLERS = {
            'len': assert_len,
            'exists': assert_exists,
            'type': assert_type,
            'header': assert_header,
            'in': assert_in,
        }
        prefix, sep, rest = assertion_str.partition(':')
        handler = ASSERT_HANDLERS.get(prefix) if sep else None

        if handler:
            handler(rest, resp, resp_json)
        else:
            path, op, expected = parse_expr(assertion_str)
            data = extract_by_path(resp_json, path)
            expected = convert_expected(expected)

            log.debug(f"断言: {path} 实际={data} {op} 期望={expected}")
            try:
                assert OPS[op](data, expected), f"{path} 实际={data} {op} 期望={expected}"
            except AssertionError:
                log.error(f"断言失败: {path} 实际={data} {op} 期望={expected}")
                raise
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `ASSERT_HANDLERS` 定义在循环内 | 每次循环重新定义，不影响功能但可优化到外部 |
| `partition(':')` | 按第一个冒号分割前缀和内容 |
| `if sep` | 只有确实存在冒号时才按前缀处理 |
| `handler(rest, resp, resp_json)` | 特殊断言需要完整响应对象和响应 JSON |
| 默认分支做数据断言 | 无前缀时按路径取值比较 |
| `OPS[op](data, expected)` | 复用运算符表，支持 ==/!=/>=/<=/>/< |
