# 测试结果回调

pytest 执行完成后，通过 `pytest_terminal_summary` 钩子统计结果并回调 Django 的 `/update_run_result/`，更新 `DB_run_result` 记录。

---

## 流程

```
pytest 全部用例执行完毕
  → pytest_terminal_summary 钩子触发
  → 统计 passed / failed / skipped
  → 计算执行耗时
  → POST /update_run_result/
  → Django 更新 DB_run_result
```

---

## pytest 端结果统计与回调

来源：`api_app/api_test/conftest.py`

```py
import os
import time
import pytest
import requests


def pytest_terminal_summary(terminalreporter, exitstatus):
    STATUS_MAP = {
        pytest.ExitCode.OK: "passed",
        pytest.ExitCode.TESTS_FAILED: "failed",
        pytest.ExitCode.INTERRUPTED: "interrupted",
        pytest.ExitCode.INTERNAL_ERROR: "internal_error",
        pytest.ExitCode.USAGE_ERROR: "usage_error",
        pytest.ExitCode.NO_TESTS_COLLECTED: "no_tests",
    }
    status = STATUS_MAP.get(exitstatus, "unknown")

    passed = len(terminalreporter.stats.get('passed', []))
    failed = len(terminalreporter.stats.get('failed', []))
    skipped = len(terminalreporter.stats.get('skipped', []))
    total = passed + failed + skipped

    start_at_ts = float(os.environ.get("STARTED_AT", time.time()))
    finished_at = time.strftime("%Y-%m-%d %H:%M:%S", time.localtime())
    duration = time.time() - start_at_ts

    test_run_id = os.environ.get("TEST_RUN_ID")
    base_url = os.environ.get("BASE_URL", "http://172.16.2.60:8000")

    payload = {
        "test_run_id": int(test_run_id),
        "status": status,
        "total": total,
        "passed": passed,
        "failed": failed,
        "skipped": skipped,
        "finished_at": finished_at,
        "duration": duration
    }

    build_url = os.environ.get("BUILD_URL")
    if build_url:
        payload["jenkins_build_url"] = build_url
        payload["report_file"] = f"report_{test_run_id}.html"

    try:
        resp = requests.post(f"{base_url}/update_run_result/", json=payload, timeout=10)
        print(f"\n[回调平台] {base_url} -> {resp.status_code} {resp.text[:200]}")
    except Exception as e:
        print(f"\n[回调平台失败] {base_url} -> {e}")
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `pytest_terminal_summary` | pytest 提供的会话级钩子，全部用例跑完后执行 |
| `STATUS_MAP` | pytest 退出码是枚举/数字，转成平台状态字符串 |
| `terminalreporter.stats` | pytest 内部统计对象，按结果类型分类 |
| `len(...)` | `stats.get('passed')` 可能返回 None，取长度安全 |
| `total = passed + failed + skipped` | 手动汇总，不依赖 pytest 的 total |
| `STARTED_AT` 从环境变量取 | 启动时由 `run_single_local` 写入，计算真实耗时 |
| `time.strftime` | 格式化时间字符串存 DB |
| `test_run_id` 强转 int | 环境变量是字符串，接口需要 int |
| `BUILD_URL` 判断 | 只在 Jenkins 环境下回填构建链接 |
| `report_{test_run_id}.html` | Jenkins 场景的报告文件名约定 |
| `try/except` 包裹回调 | 回调失败不能影响 pytest 本身的退出结果 |
| `timeout=10` | 防止网络异常导致回调挂死 |

## Django 端更新结果

来源：`api_app/views_test_item.py`

```py
import json
from django.http import JsonResponse
from api_app.models import DB_run_result


def update_run_result(request):
    data = json.loads(request.body)
    run_id = data.get("test_run_id")

    run_result = DB_run_result.objects.get(id=run_id)
    run_result.status = data.get("status", "completed")
    run_result.total = data.get("total")
    run_result.passed = data.get("passed")
    run_result.failed = data.get("failed")
    run_result.skipped = data.get("skipped")
    run_result.duration_seconds = data.get("duration")
    run_result.finished_at = data.get("finished_at")
    run_result.report_file = data.get("report_file", run_result.report_file)
    run_result.log_file = data.get("log_file", run_result.log_file)
    run_result.jenkins_build_url = data.get("jenkins_build_url", run_result.jenkins_build_url)
    run_result.save()

    return JsonResponse({
        "code": 0,
        "message": "success",
        "data": {
            "test_run_id": run_id,
            "status": run_result.status
        }
    })
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `json.loads(request.body)` | pytest 回调传 JSON，不是 form-data |
| `DB_run_result.objects.get(id=run_id)` | 直接 get，不存在会抛 500 |
| `data.get("status", "completed")` | 状态为空时默认 completed |
| `report_file` / `log_file` 取旧值或新值 | `data.get("report_file", run_result.report_file)` 没传就不覆盖 |
| 只更新关键字段 | 不更新 started_at、test_items 等创建时已确定的字段 |
| 返回 `test_run_id` 和 status | 方便前端或 pytest 确认更新成功 |
