# 执行时测试项整合

用户在前端勾选测试项并选择环境/域名/Token 后，后端按类型拆分测试项，单接口用例拼接完整请求信息后落盘为 JSON 文件，再启动本地 pytest 子进程执行。

---

## 流程

```
前端 POST /execute_run/
  → dispatch_run 接收参数
  → 按 type 拆分测试项（单接口 / 多接口脚本）
  → 单接口：build_test_item_cases 拼接完整用例
  → json.dump 落盘 {run_id}_cases.txt
  → run_single_local 启动本地 pytest
```

---

## 入口：dispatch_run（本地执行分支）

来源：`api_app/api_test/api_executor.py`

```py
import json
import os
from django.utils import timezone
from api_app.models import *


def dispatch_run(data):
    test_item_ids = data.get('test_item_ids', [])
    description = data.get('description', '')
    run_mode = data.get('run_mode', 'local')

    if not test_item_ids:
        return {"code": -1, "message": "未选择测试项"}, 400

    test_items = list(DB_TestItem.objects.filter(id__in=test_item_ids, is_del=False))
    if len(test_items) != len(test_item_ids):
        return {"code": -1, "message": "部分测试项不存在或已删除"}, 400

    type1_ids = [item.id for item in test_items if item.type == 1]
    type2_ids = [item.id for item in test_items if item.type == 2]

    base_url = data.get('base_url', 'http://172.16.2.60:8000')
    env_id = data.get('env_id')
    env_obj = DB_Env.objects.filter(id=env_id, is_del=False).first()
    env_name = env_obj.name if env_obj else ''

    results = []

    if type1_ids:
        domain_id = data.get('domain_id')
        token_id = data.get('token_id')
        header_template_id = data.get('header_template_id')

        domain_obj = DB_Domain.objects.filter(id=domain_id, is_del=False).first()
        token_obj = DB_Token.objects.filter(id=token_id, is_del=False).first()
        header_obj = DB_HeaderTemplate.objects.filter(id=header_template_id, is_del=False).first()
        if not domain_obj or not env_obj:
            return {"code": -1, "message": "域名或环境未配置（单接口用例需要）"}, 400

        headers = header_obj.headers.copy() if header_obj else {}
        if token_obj:
            headers['token'] = token_obj.token

        test_run = DB_run_result.objects.create(
            env=env_name,
            status="running",
            description=description,
            test_items=','.join(str(i) for i in type1_ids),
            started_at=timezone.now(),
            trigger_source=run_mode,
        )

        all_cases = build_test_item_cases(type1_ids, domain_obj.domain, env_obj.env, headers)
        test_run.total = len(all_cases)

        cases_dir = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "data", "cases")
        cases_txt_name = f"{test_run.id}_cases.txt"
        cases_txt_path = os.path.join(cases_dir, cases_txt_name)
        with open(cases_txt_path, "w", encoding="utf-8") as f:
            json.dump(all_cases, f, ensure_ascii=False, indent=2)
        test_run.cases_json_file = cases_txt_name

        # 【此处省略 Jenkins 分支：run_mode == 'jenkins' 时打包推 Jenkins】
        run_single_local(test_run, cases_txt_path)
        results.append({"type": 1, "run_id": test_run.id})

    # 【此处省略 type2_ids 多接口脚本分支】

    return {"code": 0, "message": "success", "results": results}, 200
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `test_item_ids` 是数组 | 前端传 JSON 数组，不是逗号字符串 |
| `len(test_items) != len(test_item_ids)` | 校验所有 ID 都存在，防止传入无效/已删除 ID |
| `type1_ids` / `type2_ids` | 单接口和多接口脚本分开执行，流程不同 |
| `domain_obj` 和 `env_obj` 必填 | 单接口执行必须知道域名和环境 |
| `header_obj.headers.copy()` | 复制模板头，避免修改原始模板数据 |
| `headers['token'] = token_obj.token` | 把 token 注入请求头 |
| `test_items=','.join(...)` | 多个测试项 ID 用逗号拼接存字符串 |
| `trigger_source=run_mode` | 区分 local 和 jenkins，结果列表也按来源分组 |
| `ensure_ascii=False` | 中文正常落盘 |
| 先写文件再启动 pytest | 保证子进程启动时 cases 文件已存在 |

## 拼接单个测试项的用例

来源：`api_app/api_test/api_executor.py`

```py
def build_test_item_cases(test_item_ids, domain, env, headers):
    all_cases = []
    for item_id in test_item_ids:
        test_item = DB_TestItem.objects.get(id=item_id)
        interface = test_item.interface
        base_url = "https://" + interface.url.format(domain, env)
        for case in test_item.cases:
            all_cases.append({
                'url': base_url,
                'method': interface.method.upper(),
                'headers': headers,
                'CaseID': case['CaseID'],
                'case_name': case['case_name'],
                'is_active': case['is_active'],
                'body': case['body'],
                'expected_status_code': case['expected_status_code'],
                'assertions': case['assertions'],
                'description': case['description']
            })
    return all_cases
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `DB_TestItem.objects.get(id=item_id)` | 不处理 DoesNotExist，上层已校验过存在性 |
| `interface.url.format(domain, env)` | 接口 URL 里含 `{domain}` `{env}` 占位符，执行时替换 |
| `"https://" + ...` | 固定 HTTPS 协议头 |
| `interface.method.upper()` | 统一大写 |
| `headers` 统一传入 | 所有 case 共用同一套 headers（含 token） |
| `test_item.cases` | 直接取 DB 中 JSONField 存储的用例列表 |
| 字段名 `CaseID` 大写 | 与 Excel 模板列名保持一致 |

## 本地启动 pytest

来源：`api_app/api_test/api_local_single_runner.py`

```py
import os
import subprocess
import time

BASE_DIR = os.path.dirname(os.path.abspath(__file__))


def run_single_local(test_run, cases_txt_path):
    started_ts = time.time()

    log_file_name = f"{test_run.id}_app.log"
    test_run.log_file = log_file_name
    test_run.save()

    pytest_env = os.environ.copy()
    pytest_env["TEST_RUN_ID"] = str(test_run.id)
    pytest_env["LOG_FILE_NAME"] = log_file_name
    pytest_env['STARTED_AT'] = str(started_ts)

    subprocess.Popen(
        ["pytest", os.path.join(BASE_DIR, "run_request.py"), "-v", f"--cases-file={cases_txt_path}"],
        env=pytest_env,
        cwd=BASE_DIR,
    )
```

### 特殊处理说明

| 代码 | 特殊处理原因 |
|------|-------------|
| `os.environ.copy()` | 复制当前环境变量，避免污染父进程 |
| `TEST_RUN_ID` / `LOG_FILE_NAME` / `STARTED_AT` | 通过环境变量传给 pytest，供后续回调使用 |
| `subprocess.Popen` | 非阻塞，Django 立即返回“执行中” |
| `cwd=BASE_DIR` | 在 api_test 目录下跑，保证 import 路径正确 |
| 入口是 `run_request.py` | 不是 `tests.py`，run_request.py 里同时包含执行逻辑和 pytest 入口 |
| `-v` | 详细输出，便于日志排查 |
