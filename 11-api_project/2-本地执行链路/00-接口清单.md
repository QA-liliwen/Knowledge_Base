# 单接口数据链路 - 接口清单

来源：`api_project/urls.py`

| URL | 视图函数 | 说明 | 笔记位置 |
|---|---|---|---|
| `upload_case/` | `upload_case` | 上传用例 xlsx，解析后返回 JSON | 02-Excel上传 |
| `execute_run/` | `execute_run` | 执行测试入口，调用 dispatch_run | 03-执行时测试项整合 |
| `update_run_result/` | `update_run_result` | pytest 执行完毕回调，更新测试结果 | 06-测试结果回调 |

**说明**：

- `upload_case/` → `read_single_case()` 解析 Excel → 返回 cases 数组。
- `execute_run/` → `dispatch_run()` 按 type 拆分 → `build_test_item_cases()` 拼接 → `run_single_local()` 启动 pytest。
- `update_run_result/` → conftest.py 在 pytest session 结束时回调此接口。
